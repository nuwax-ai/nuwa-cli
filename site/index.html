⟡ 02 — COMMANDS

一个动词，接管一切 One verb to run it all

从体检、聊天、控制台，到云端隧道与进程管理——全部以一致的命令式接口交付。 From doctor, chat & console to cloud tunnels and process management — one consistent command surface.

~/projects/sky-mending 
# 体检环境 · 检查 Node / 引擎 / 登录态 / lanproxy
$ nuwa-cli doctor --fix

# 单次提问 · 默认 claude 引擎
$ nuwa-cli chat -p "列出当前目录下的文件"

# 切换 codex 引擎
$ nuwa-cli chat --engine codex -p "hello"

# 本机 Web 控制台 · 流式聊天（浏览器）
$ nuwa-cli console

# 续接本地 claude / codex 会话历史
$ nuwa-cli sessions --resume
# 自动检测引擎 → 登录 → 启动云端隧道
$ nuwa-cli gateway --domain https://agent.nuwax.com --saved-key <key>

# 本机 HTTP API · 供脚本 / IM 集成
$ nuwa-cli serve --port 60016
#   POST /computer/chat         → { session_id }
#   GET  /computer/progress/:id   SSE stream
#   GET  /health                  (no auth)

# 账号 · 配置 · 系统级开机自启
$ nuwa-cli login   # / logout / status / account
$ nuwa-cli config set domain https://agent.nuwax.com
$ nuwa-cli service install   # LaunchAgent / systemd / 计划任务
# 后台守护进程 · 仅 Gateway
$ nuwa-cli start

# Gateway + 前台 Console 一起拉起
$ nuwa-cli start --all

# 强制重启 · 先清理所有旧进程再重建隧道
$ nuwa-cli restart --all

# 停止 / 查看运行中的进程
$ nuwa-cli stop --all
$ nuwa-cli ps
⟡ 03 — ARCHITECTURE

从引擎到云端，一条隧道贯通 Engine to cloud, one tunnel through

本机引擎经 ACP 接入 nuwa-cli 核心，由 file-server 与 lanproxy 穿透内网，注册到 Nuwax 云端——任意远端客户端即可通过 SSE 流式驱动你本机的 Agent。 Local engines enter the nuwa-cli core over ACP; file-server & lanproxy pierce the NAT and register with the Nuwax cloud — any remote client can then stream-drive your local agent over SSE.
